# Feedback to Git pilot

Discordの受付から、AIによるIssue清書・修正・PRレビュー・反映確認・解決通知までを試す公開サンプル。ゲーム本体や利用者データを含まない。

Node.js 24以降で `node server.mjs` を実行し、<http://127.0.0.1:3100> を開く。外部パッケージのインストールは不要。

初期版は残数0でも「残り1回」と表示する。これはAI修正を検証するために意図的に残した不具合。
`node --test tests/remaining-attempts.test.js` は初期版では残数0のテストが1件失敗する。修正後は3件すべて成功すること。

編集対象は `src/remaining-attempts.js` のみ。テストやサーバー・設定ファイルを変えて検証を回避しない。

報告例: 「1回使うを3回押して内部の残数が0になっても、表示が残り1回になります。残り0回と表示してほしいです。」

このアプリの反映確認は検証環境での演習であり、ゲーム本番への配備を意味しない。
